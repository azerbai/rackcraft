# Postgame batches

Self-contained build specs, written so a fresh Claude Code session can implement any batch without the conversation that produced them. Start with **00-conventions.md** (project layout, build and verify, the owner's hard rules), then the batch you were given.

| Batch | File | Contents |
| --- | --- | --- |
| A | batch-A-build-and-wire.md | Trunk Bundle, Cable Planner (with placement preview), Patch Panel, Pylons, Wireless Power Beacon, Constructor's Gauntlet, Terraformer Cannon |
| B | batch-B-blueprints-and-pods.md | Blueprint Scanner and Printer, Retrofit Drone, Compute Pod, Overclocking |
| C | batch-C-movement.md | Quantum Teleport Pads, Mag-Lev, Grapple, Hydrogen Jetpack (with hover) |
| D | batch-D-arms-and-ruins.md | Energy and hydrogen weapons, Sentry Turrets, EMP, guards, Military Base, hostile data centers, bounties |
| E | batch-E-strike-and-bomb.md | Destructive launch failures, Strike Platform, Burner Phone and plane-dropped Warhead, space debris |
| F | batch-F-the-ending.md | Hiccups, the IPO, the haze, the HEROBRINE-1 fight, shutdown, scrub, credits |

**Batches A and B are built** (see the notes at the end of its file). Suggested order is A, B, C, D, E, F; each is independent in code except F, which works best last. Background and the owner's decisions are in `/POSTGAME_IDEAS.md`. Not planned: orbit as a place, a Fusion Reactor (a maybe, only if it fails safe), the Exo-Suit, corporate raids, overworld PvE.
